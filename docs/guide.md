# 企业开通指南

本指南介绍企业管理员如何开通账号、下载插件、添加团队成员以及查看积分消耗。

---

## 一、企业管理员账号开通 {#admin-account}

您提供的邮箱会收到一封包含管理员账号密码及登录地址的邮件，请根据邮件信息登录企业运营平台。

![企业管理员账号开通邮件](/guide/admin-email.webp)
_企业管理员账号开通邮件_

---

## 二、下载插件 {#download-plugin}

登录企业运营平台后，在「产品下载」页面下载 VS Code 插件。

![产品下载页面](/guide/product-download.webp)
_产品下载页面_

---

## 三、添加团队成员 {#add-members}

### 方式一：通过邀请链接邀请成员加入 {#invite-link}

复制邀请链接发给团队成员。

![邀请链接](/guide/invite-link.webp)
_邀请链接_

成员通过邀请链接申请加入后，在「待审批」列表中审批通过并选择角色，成员即加入成功。

![待审批列表](/guide/pending-approval.webp)
_待审批列表_

![审批通过并选择角色](/guide/approve-role.webp)
_审批通过并选择角色_

![成员加入成功](/guide/member-joined.webp)
_成员加入成功_

成员在插件中通过 `/login` 登录即可正常使用。

::: tip 计费说明
管理员和普通成员均为计费用户。
:::

### 方式二：配置 SSO 登录 {#sso-login}

登录信息配置完成后，点击「测试连接」，连接成功即可正常使用。

![配置 SSO 登录](/guide/sso-config.webp)
_配置 SSO 登录_

公司成员在页面输入邮箱地址，点击「SSO 登录」。若邮箱地址符合 SSO 设置的邮箱，该成员即可自动加入团队。

![SSO 登录页面](/guide/sso-login.webp)
_SSO 登录页面_

---

## 四、查看积分 {#view-credits}

管理员角色查看的是团队内所有的积分消耗记录；普通成员查看自己的积分消耗。

可按调用次数、日期和成员聚合查看积分消耗。

![查看积分](/guide/credits-view.webp)
_查看积分_
