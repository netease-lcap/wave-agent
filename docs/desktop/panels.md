# 面板介绍

## 面板介绍

对话级侧面板与聊天区并排展示，通过顶栏「面板」菜单多选开关（可同时开启多个），各分屏的面板开关状态与内容相互独立。快捷键：预览 `⇧⌘P`（Windows `Ctrl+Shift+P`）、差异 `⇧⌘D`（`Ctrl+Shift+D`）、终端 `` ⌃` ``（`` Ctrl+` ``）；计划与文件面板无快捷键。

![面板开关](/screenshots/desktop-panel-toggle.webp)

### 1）预览面板

在窗口右侧预览本地开发服务器（如 Vite 原型）页面，边对话边查看原型：

- 点击消息中的 localhost 链接（`localhost`、`127.0.0.1`、`[::1]`，任意端口）在面板中打开，非 localhost 链接仍用系统浏览器打开
- 消息中指向本地 `.html` / `.htm` 文件的路径也在本面板打开并渲染页面；渲染失败时回退到文件面板，本面板不提供该文件的源码视图
- 支持多标签页，同一面板内导航；dev server 热更新自动反映改动，提供绕过缓存的强制刷新与「在浏览器打开」
- **切换会话时页面保活**：切走再切回原会话，地址栏地址、页面自身状态与滚动位置原样保留，不会重新加载；同时保活的页面全局上限 4 个，超出时按最久未使用淘汰。只有在关闭该预览标签页、删除会话、关闭所在分屏或退出应用时才真正销毁——**这一点与下一小节「终端面板」正好相反**（终端 PTY 随会话切换终止）
- **全屏时对话不消失**：tab 栏右端的全屏按钮让面板铺满内容区，此时对话列缩成预览区底部居中的悬浮对话框（消息列表、任务清单与消息队列不显示，输入框与发送逻辑不变）。发送后对话框换成「正在工作」加载态，本轮结束后恢复为空白输入框；退出全屏后输入框里还没发出去的内容、对话的滚动位置都还在，光标回到输入框
- 工具栏提供**元素拾取**：悬停元素显示高亮轮廓、点击后添加评论，评论连同元素上下文追加到输入框，可连续拾取、统一编辑后一起发送（详见 [4.2 Localhost原型预览与元素评论](./coding-assist#localhost原型预览与元素评论)）

### 2）计划面板

当 AI 制定执行计划并准备退出计划模式时（ExitPlanMode），计划全文自动展示在计划面板中（对话确认框只保留精简摘要）；也可通过 `/plan` 在会话中查看当前计划文件。计划内容按 Markdown 渲染，支持表格、代码块等。

![计划面板](/screenshots/desktop-plan-pane.webp)

### 3）差异面板

实时查看当前对话相对仓库基线的全部改动（agent 已提交到会话分支的、工作区尚未提交的、以及尚未跟踪的新文件），不离开应用即可审查 agent 这一轮到底改了什么：

- **变更基准**：会话分支相对仓库默认分支的分叉点（`git merge-base HEAD <默认分支>`），无默认分支时退化为 `HEAD`（只看未提交改动），仓库尚无 commit 时退化为已暂存内容；工具栏只读展示 `{变更基准} → 工作树`、改动文件数与总增删统计
- **左侧栏（文件树 + 提交选择）**：按路径层级组织、目录可折叠、文件行显示 `+N −M`（完整路径在 title 中），点击文件即展开并滚动到该文件；文件树下方按新→旧列出变更基准到 `HEAD` 之间的提交（首项「全部改动」默认选中），选中某条后文件数 / 统计 / 文件树 / 内容都切到该提交自身的改动；显隐状态与所选提交随会话记忆，槽位过窄放不下文件树与可读宽度的差异区时左侧栏自动隐藏、加宽即恢复（不改写显隐记忆）
- **统一 / 并排视图**：工具栏可切换；并排视图为左旧右新两列（各带行号），配对不足的一侧补空位；切换只换排布，不重新请求数据
- **大规模差异降级**：范围内总增删超过 5000 行时默认折叠全部文件并提示「差异过大，已折叠全部文件」；单文件超过 1000 行时该文件不做词级高亮（保留行级增删底色与行评论）；单文件内容仍按 2000 行上限截断并提示
- 以手风琴形式逐文件展示：文件头部显示相对路径、状态标识（新增 / 修改 / 删除 / 重命名 / 未跟踪）与增删行统计，展开区为增删行高亮的差异内容（含词级高亮）
- 一轮生成结束后自动刷新为最新改动，也提供手动刷新；刷新期间保留现有内容直至新数据到达
- 支持在差异行上添加评论，评论追加到输入框与 agent 沟通
- 非 git 目录显示「非 git 仓库」空状态，无改动时显示「无改动」

### 4）终端面板

在对话旁打开一个真正的终端，以该对话工作目录为 cwd 启动登录交互会话，无需离开应用即可验证改动或执行辅助操作：

- 真 PTY 会话，支持 vim、top 等交互式程序，按键全量透传，Ctrl+C 中断前台程序
- 输出含 ANSI 颜色正确渲染，面板宽度变化时同步重排；剪贴板与系统互通
- 取消勾选再重新勾选时，shell 会话与滚动输出原样保留；工具栏提供「重启终端」
- 终端输出中的 localhost 链接与消息一致：在预览面板打开，非 localhost 链接用系统浏览器打开
- 关闭分屏 / 删除会话 / 退出应用时终止 PTY 进程，不残留孤儿进程

![终端面板](/screenshots/desktop-terminal-pane.webp)

### 5）文件面板

点击消息中 read / edit / write 工具的文件路径，在右上角打开文件面板查看文件内容，无需离开对话即可核对 agent 读写过的文件：

- 本地与远程（SSH）会话统一承载文件查看；本地会话额外提供「在默认应用中打开」
- 例外：本地 `.html` / `.htm` 路径优先在**预览面板**渲染页面，渲染失败才回退到本面板；本面板是「源码 / 文本」视图，不为这类文件提供源码查看入口
- 行号、长行水平滚动（行号列固定）、按扩展名语法高亮；Markdown 文件按渲染后展示，图片文件内联预览
- 带起止行信息时自动滚动定位；支持复制完整路径、面板内搜索；文件过大或二进制时截断 / 拒读并提示
- 本地会话可直接在面板里改文件：工具条「编辑」进入编辑态（带行号的编辑器），改完点「保存」或按 `⌘S` / `Ctrl+S` 写回磁盘，正文回到只读并提示「已保存」；Markdown 文件编辑的是源文本，保存后回到渲染视图
- 保存前会比对磁盘上的内容：文件已被 agent 或外部编辑器改过时不覆盖，面板提示「文件已在磁盘上更新」，由你选择「覆盖」（写入自己的版本）或「重新加载」（丢弃修改、回到磁盘内容）；写盘失败时草稿保留，可重试或取消
- 有未保存的修改时，打开另一个文件、关闭面板、切换会话或工作目录、新建 / 删除会话都会先确认是否放弃；选「继续编辑」则原操作不执行、草稿原样保留
- 远端会话的文件面板仍只读；内容被截断的超大文件、二进制与图片不提供编辑入口
- 面板内编辑面向顺手改一处，不提供多光标、查找替换、格式化等能力，重活仍用「在默认应用中打开」跳到外部编辑器；保存需手动触发（不自动保存），未保存的草稿不跨应用重启保留
- 支持在代码行上添加行评论（与差异面板同一交互）：右键某行选「添加评论」，或选中连续几行后点选区末尾浮出的按钮，在该行（或该段行）下方展开输入框，写下的评论连同文件路径、行号（或行区间）与该处内容追加到消息输入框（不直接发送，可连续评论多行后统一发给 agent）；工具条上的「评论」按钮对当前选区或最近点击过的那一行打开同一个输入框；Markdown 文件按块评论——悬停标题 / 段落 / 列表项 / 引用 / 表格单元格 / 代码块时块外侧出现「+」，追加内容带该块的文本片段、不带行号；图片不提供评论入口；编辑态下不提供评论入口
- 手动勾选「文件」面板且还没打开具体文件时，正文先列出**这次对话读写过的文件**（最近的在前，点一行即在面板内打开），不会翻消息流也能找到文件；当前对话还没有文件、也还没打开过文件时才显示「打开的文件会显示在这里」占位（正文左侧是该会话的目录树，可直接从树里点开文件）。清单来自对话本身，不列创作集（artifact 是服务端链接，没有文件与文件夹的概念）
