# 功能规格说明：右下角通知组件

**创建日期**：2026-08-05
**更新日期**：2026-08-05

## 用户场景与测试 _（必填）_

### 用户故事：右下角的 token 用量指示（优先级：P1）

作为开发者，我希望 token 用量（上下文百分比）由独立的右下角通知组件显示，以便与 Claude Code 的布局对齐：左下状态栏只显示模式/shell 状态，右下通知区显示 token 用量与登录提示。

**验收场景**：

1. **假设** CLI 正在运行且尚未收到 AI 响应，**则** 右下角通知区不显示百分比（已消耗 0 个 token）。
2. **假设**已收到 AI 响应且上下文窗口已知，**当**尚未到自动压缩阈值时，**则** 右下角显示灰色的 "N% until auto-compact" —— **剩余**百分比，分母是自动压缩阈值（窗口 200000 + 最大输出 32000 ⇒ 阈值 167000；已用 40000 时显示 "76% until auto-compact"）。句子里必须出现 "until auto-compact"：裸的 "N% context" 会被读成「占窗口 N%」，那是图形界面环的口径。
3. **假设**剩余比例低于 20%（已用超过阈值的 80%），**当**显示通知区时，**则** 文本变为黄色。
4. **假设**剩余比例低于 5%（已用超过阈值的 95%），**当**显示通知区时，**则** 文本变为红色。
5. **假设**已用达到或超过自动压缩阈值，**当**显示通知区时，**则** 不再报数字，显示 "auto-compact next"（对齐 Claude Code 的同一分支：压缩就在下一轮之前发生）。
6. **假设**用户处于 BTW 模式，**则** 输入区域显示独立的 `BtwDisplay` 组件，状态栏与通知区均不显示。
7. **假设** AI 正在思考，**当**显示加载指示器时，**则** 加载指示器保持显示 "1,234 tokens" 计数，通知区百分比与其互不影响。
8. **假设**上下文窗口未知（为 0），**当**显示通知区时，**则** 这一格整块不渲染 —— 不误报 "auto-compact next"（那是「到阈值了」的语义，不是「算不出来」）。
9. **假设**同一会话同时开着终端与图形界面，**当**两端各显示用量时，**则** 终端那一格是**剩余 / 阈值**（`packages/code` 的 `remainingPercentOf`），图形界面输入框旁的环是**已用 / 窗口**（`ringPercentOf`，见 [context-usage-indicator.md](context-usage-indicator.md) 场景 4）—— 两者的分母与方向都不同，各自在自己那一端成立；CLI 不因图形界面对齐而改变。

### 用户故事：右下角的登录提示（优先级：P1）

作为新用户，我希望在未认证时于右下角看到登录提示，以便与 Claude Code 的提示位置一致（"Not logged in · Run /login" 位于右下通知区）。

**验收场景**：

1. **假设** CLI 正在运行且用户没有任何可用的认证或直连 API 配置，**则** 右下角通知区显示 "Type /login to authenticate" 提示。
2. **假设**用户完成登录，**则** 右下角登录提示实时消失。
3. **假设**消息区仍在渲染欢迎消息或静态内容，**则** 登录提示不显示在消息流中。

### 边界情况

- **BTW 模式激活时通知区显示吗？** 不显示。BTW 模式下输入区域整体替换为 `BtwDisplay`，状态栏与通知区一并隐藏。
- **登录提示与百分比同时出现时如何排列？** 两者均位于右下角通知区，按顺序排列显示。
- **上下文百分比为 0（未收到响应）时显示吗？** 不显示，与拆分前行为一致。
- **显示时机是常显，不是 CC 的「临近阈值才出现」**：Claude Code 的这条 token warning 只在压力达到 warn 级时渲染（阈值 − 20,000 tokens，窗口 200k ⇒ 约 147k 起）；wave 目前**一直显示**（只要有 token 且窗口已知），好处是平时也能看到进度。收窄成 CC 的口径会丢掉这部分信息，属产品决策，本轮未改（2026-11-26 记录）。
- **为什么没有 CC 的 "Context low (N% remaining) · /compact to free up space"**：那是 CC 在**自动压缩不可用/被禁用**（`DISABLE_COMPACT` 或远端禁用 compact）时的兜底文案。wave 没有「关掉自动压缩」这个状态，压缩一定会发生，所以只有 "auto-compact next" 这一支。
