# 功能规格说明：会话消息大纲

> 本规格描述「在一条长会话里跳回某一轮问答」的导航入口。形态对齐 Codex 桌面端：内容区左边缘一列等距短刻度，一个刻度 = 一条用户消息，悬停出预览卡，点击落位。作用域是**当前会话已加载的内容**；按内容查找某一句话见 [transcript-find.md](./transcript-find.md)。

## 用户场景与测试

### 用户故事：会话消息大纲（优先级：P2）

作为用户，我希望在长会话里一眼看到「我问过哪几件事」，点一下就跳回那一轮问答，以便在一条跑了几十轮、每轮都带大段工具输出的会话里不用靠滚轮找自己的问题。

**为什么是这个优先级**：会话只会越跑越长（工具调用、后台任务输出、子代理结果都在往里堆），而现在的导航入口只有「往上滚」和吸顶条（只能看到上一条被滚过去的用户消息，且只能点回最近的一条）。对齐 Codex 桌面端已经验证过的形态；不引入新的数据依赖——大纲项完全由会话里已有的用户消息派生。

**独立测试**：打开一条几十轮的会话，验证左边缘出现一列刻度、刻度数等于其中的用户消息数；上下滚动验证高亮跟着变到**视口内最靠上**的那一轮，继续滚进某一轮的回答中间（屏里看不到任何用户消息）验证**没有任何刻度高亮**；悬停任意刻度验证预览卡出现且内容就是该轮的用户消息；点击某个刻度验证滚到那一轮、**该刻度本身变成高亮**（不是上一轮）、且不再被流式内容拽回底部，再滚动一次验证高亮重新按滚动判据走；把面板拖窄到阈值以下验证刻度整体消失，拖回去验证重新出现；在会话仍处于流式生成时点击刻度，验证落位与高亮都不被新内容打断。

**验收场景**：

1. **假设**会话内容区已加载且其中**至少两条**用户消息，**当**用户查看内容区左边缘，**则**必须显示一列竖排刻度大纲，位置在内容列**左侧的留白里**（距滚动面左边缘 **12px**，与消息列之间留有明显间距，不与气泡贴在一起）、**不占用正文宽度**（正文列的可用宽度与无大纲时完全一致）；每条可选用户消息对应一个刻度。
2. **假设**会话只有一条用户消息，或者没有任何用户消息，**当**查看内容区，**则**不显示大纲（一条刻度没有导航价值，不该占位）。
3. **假设**大纲已显示，**当**判断「哪些消息成为刻度」，**则**只列用户消息中**带文本**的那些：注入型隐藏消息（`isMeta` 的规则提醒、钩子上下文、任务通知等）与没有文本块的用户消息（纯任务通知）都不列——与吸顶条「能否作为锚点」的判据必须是**同一个**，不得出现「吸顶条认它、大纲不认它」的分叉。
4. **假设**大纲已显示，**当**用户滚动内容区，**则**必须把「当前这一轮」的刻度标为高亮态（**只改颜色**：前景色；宽度不参与——没有悬停时它仍是一长一短里的那一档 10px / 6px，指针压在它身上时才跟着涟漪加宽到 24px；其余刻度为浅色）；**这处高亮只在操作期画**——指针压在刻度列上、或正在翻动刻度条时才出现，指针一离开整列就收回，静止的一列短横上不留「选中态」（见场景 14）；滚动时的判据是**视口内可见的最靠上的那条用户消息**——一屏里同时可见多条用户消息时取最靠上的那条（它才是读者正在读的这一轮的起点，靠下那条是还没开始读的下一轮，不得因为它在视口底部露头就提前抢走高亮）；**视口内一条用户消息都看不到时（读者正处在某一轮的长回答、大段工具输出中间），不标任何高亮**——高亮只标记屏幕上看得见的那一轮，不点亮已经滚出屏幕的消息、也不做「退回吸顶那条」的兜底。因此高亮的亮区间就是这条用户消息自身的可见区间：进入视口才亮、整个滚出就灭，切换与熄灭落在同一处边界。吸顶条另有自己的判据（滚出视口顶的最近一条），两者**不要求**指向同一条消息。唯一的例外是刚点过刻度：那一次点击的落点由场景 6 说了算，直到用户再次滚动。
5. **假设**大纲已显示，**当**用户把指针悬停在某个刻度上（或键盘把焦点移上去），**则**该刻度的短横必须从常态宽度**渐宽到 24px**（0.12s 过渡，不是瞬间跳宽），**并且上下相邻的几条按距离递减同向变宽**（±1 格 19px、±2 格 13px，再远回到一长一短的 10/6），形成一个围绕指针的渐变簇；同时必须在该刻度右侧弹出预览卡（**皮肤整套与 Tooltip 一致**：面 `--cc-bg-overlay`、边 `--cc-border`、字 `--cc-text-primary`、圆角 8、内衬 4/12、字 12/20 常规字重、阴影 `--cc-shadow-popover`——两者是同一族浮层，不另造一套），**卡片里只有这一条用户消息的文本**（最多 3 行，超出截断；不显示助手回答、不做「标题 + 正文」两段式——这么小一块地方，两段内容只会互相重复）；预览卡**不得溢出内容区**——宽度随列宽自适应，窄列下收窄到「列宽 − 24px」，垂直方向贴住刻度的位置并对屏幕边缘做夹取。
6. **假设**用户点击某个刻度，**当**该刻度对应的消息在已加载的消息里，**则**必须立即把该消息落位到视口内（不播放长距离平滑滚动动画），**并把它自己标为高亮刻度**——点击是「我要看这一轮」的显式意图，高亮不得停在上一轮（落位把目标放在视口中间时，折线之上仍是上一轮的尾巴，此时按场景 4 的滚动判据算出来的会是上一轮，这不是用户要的结果）；同时**松开「跟随新内容」的状态**：随后到达的流式内容、工具输出、压缩提示都不得把视口拽回底部。点击带来的「当前这一轮」保持到用户**再次滚动内容区**为止（滚轮、触控拖动、键盘翻页、拖动滚动条任一），之后重新按场景 4 的判据计算；期间流式内容追加、更早一页加载都不得把高亮改回上一轮。它与场景 4 一样**只在操作期显形**：点完把指针移开，整列不再留那一笔深色（点击后指针仍压在刻度上时，它就跟着悬停簇一起亮着）。
7. **假设**目标消息位于虚拟列表尚未渲染的区段，**当**用户点击该刻度，**则**仍必须落位成功——定位必须按消息在列表中的位置计算，不得依赖目标行是否已挂载在 DOM 上。
8. **假设**大纲已显示，**当**会话正在流式生成（新消息、工具输出不断追加），**则**大纲必须随新增的用户消息增长、且不打断用户正在进行的悬停与阅读；已在列表中的刻度不得因流式刷新而跳动或重排。
9. **假设**会话消息是分页加载的（历史还有更早的页未取），**当**用户查看大纲，**则**大纲只包含**已加载**消息里的用户消息；用户上翻触发更早一页加载后，大纲必须随之增长（更早的刻度补充在上方），不得报错、不得重置当前高亮。
10. **假设**内容列**还没撑满最大宽度**（800px，窄分屏、IDE 侧栏、手机远控页），或撑满之后两侧留白**不足 40px**，**当**查看内容区，**则**整个大纲**不显示**——刻度必须与消息列之间有实际的间距，没有这片留白就不画（与 Codex 一致：不给窄版形态、不做折叠抽屉），内容列宽度与无大纲时完全一致；把窗口拉到留白足够后大纲必须重新出现。
11. **假设**大纲已显示且用户消息数量较多（几十条），**当**渲染刻度，**则**刻度必须**等距**排布（不按每条消息的实际高度成比例）、**密排**（一列短横而不是几个散点），且未选中的刻度**一长一短**相间（长 10px、短 6px，均为 2px 高——与 Codex 那种等长梳齿区分开）；两条短横之间固定留 8px 空白，即**节距恒为 10px**，与条数、视口高无关——不随条数压缩间距，也不抽样丢项；排不下时由刻度条自身滚动（见场景 13）。
12. **假设**用户切换会话（或该分屏换了会话），**当**新会话内容渲染出来，**则**大纲必须按新会话的用户消息重建，不得残留上一会话的刻度、高亮位置或展开的预览卡。
13. **假设**刻度条的自然高度超过整条上限（= 「滚动面高 − 160px」的 2/3，上下各留 80px 之后再收一档；814 高下是 436px），**当**渲染刻度条，**则**刻度条本身变成可滚动区（上限再减去上下各 28px 的箭头格：按钮盒 20px + 与刻度之间 8px 空白）、**上下各出现一支 20×20 的箭头**（墨迹左缘与刻度左缘对齐；与最近一条刻度之间留 8px；不画滚动条；**常态不显形，指针进到刻度列里才浮现**——0.18s 淡入淡出，盒子始终占位所以整列高度与刻度位置不动，键盘聚焦到那一支时同样浮现）：点箭头一次滚**固定 20 个刻度**（200px；与「一屏装得下多少」脱钩，按一下不会直接贴到某一端，翻完仍留下大片重叠的刻度当上下文），滚到顶/到底的那一支换成**禁用档字色**（`--cc-text-disabled`）但保留占位（避免刻度列随箭头出现/消失上下跳）；指针停在刻度条上时**滚轮只滚刻度条、正文界面一律不动**（滚到尽头就停住，**不得**把滚动交还给消息列表——一次连续手势在末尾忽然变成翻正文，读者会以为还在刻度上）；可滚区上下各有一段 20px 的渐隐蒙版（用 `mask-image`，不盖纯色层：底下是正文面，盖色会露色差），但**只在正在翻动时出现**：停止滚动约 0.42s 后两侧收起为 0（长度走 0.18s 过渡，用注册成 `<length>` 的自定义属性插值——`mask-image` 本身不可插值），静止时整列逐像素与「没有蒙版」相同；**滚到那一端时该侧同样收起为 0**。于是「这一头还有没有下一格」只在翻动时读到，静止的短刻度列不会无端被淡掉一截。滚动任何一端都不得把预览卡推出滚动面——可滚区只装刻度，预览卡挂在它外面按其位置计算纵向位置。
14. **假设**大纲已显示且指针没有停在任何刻度上，**当**查看刻度列，**则**所有刻度必须回到「一长一短」的常态宽度；但**对应的用户消息此刻落在滚动面内**的那几条，颜色要留在较深的一档（次要文字色，与悬停同色、不叠透明度），宽度不变——读者据此看出「我现在正在读的这几轮」是哪几条。判据是**消息行与滚动面相交**，按行的偏移表计算（虚拟列表只挂载可见行，不得靠 DOM 是否存在来判）；这与场景 4 的「当前这一轮」（视口顶**之上**最近的那条，可能在屏幕之外）是两个独立概念；静止态**只画这一档**——「当前这一轮」那条在指针离开刻度列后也回到这一档（不再留一笔前景色，见场景 4），所以整列静止时最多只有两种颜色：禁用档与次要档。**「在视口内」的提色只在大纲空闲时成立**：指针压在某条刻度上、或刻度条正在翻动时，整列只留两处高亮——跟着指针的那一簇（涟漪宽度 + 次要档颜色）与「当前这一轮」（前景色），其余刻度一律回到禁用档；操作结束（指针移开、翻动停止约 0.42s）后提色恢复。
15. **假设**刻度条可滚动（刻度数超过整条上限），**当**用户翻动正文、点刻度跳转，或流式内容/滚动把「当前这一轮」换成另一条（按场景 4 的判据换人），**则**刻度条必须**自动滚动**，让这一轮对应的刻度留在可见范围内：**最小幅度**地挪（不居中，贴着某一侧时只挪动到够用的距离），并在该刻度与上下边缘之间**留出 2 格余量**（贴边时既看不出还有没有刻度，也点不着）；会话翻到最顶、还没有「视口顶之上最近的一条」时，锚点退回**视口内最靠上的那条消息**，不得停在原处不动。用户正把指针停在刻度条上、或正在翻动刻度条时**不得抢滚动**（此时锚点换了人也先不动），但松手后要补上这一次；如果用户是自己翻动刻度条去看别处，则等她再次翻动正文（锚点换人）时才归位。自动跟随只滚刻度条，**不得**带动正文，也不得触发上下蒙版与「在视口内」提色的切换。

## 边界情况

- **超长用户消息**：预览卡只取开头数行，不得把整段长文本塞进卡片；悬停不得因截断长文本而卡顿。
- **一屏内多轮问答**：视口里同时可见多条用户消息时，高亮固定取**最靠上**的那条，不得因为靠下那条在视口底部露头就提前跳亮。点过刻度之后到下次滚动之前，以点击的那条为准（场景 6），不因为落位后上一轮仍在视口里就退回上一轮。
- **屏里一条用户消息都没有**（正在读某一轮的长回答、大段工具输出）：**不标任何高亮**，不做「退回吸顶那条」的兜底。高亮只表示「这一轮的问题消息就在你屏幕上」，读者已经滚进正文时没有刻度该被点亮；再往下滚到下一轮的问题进入视口时高亮才出现。
- **会话为空 / 首屏加载中**：消息尚未到达时按场景 2 处理，不显示占位刻度。
- **与查找条、吸顶条共存**：三者同屏互不遮挡；查找条跳转与大纲跳转都要松开跟随状态（同一条语义），互不覆盖对方的结果。
- **无悬停设备**（触屏、手机远控页）：不做长按/点击出预览的替代交互；这类形态通常已落到「窄于阈值不显示」的情形。
- **IDE 侧栏的默认宽度**：VS Code / JetBrains 侧栏默认只有 400px 上下，连消息列的 800px 上限都到不了，按场景 10 大纲**默认不出现**；把面板拉宽到 ≥ 880px 左右才会看到。这是有意为之（窄栏里正文最宝贵、也放不下目录与正文之间的间距），不视为缺陷。
- **刻度的颜色全部取自既有的文字色阶**（不新造中间色、不用 `opacity` 调淡）：常态 = 禁用档 `--cc-text-disabled`（**深色档压暗一档到边框色阶 `--cc-border`**：文字色阶再往下没有了，禁用档已是最后一档），hover 与「在视口内」= 次要档 `--cc-text-secondary`，当前这一轮 = 前景色；箭头的可用态 = 次要档、hover = 前景色、到端禁用态 = 禁用档。非桌面宿主回落到 `--vscode-*` 同名变量。
- **条目极多（超过整条上限，814 高下 44 条起）**：刻度条自身滚动（见场景 13）；814 高下整条上限 436px、可滚区 380px（看到 38 条）、点箭头一步 200px（20 条）。整条仍垂直居中、首末刻度不会贴到滚动面边缘，预览卡始终留在滚动面内。

## 非目标（明确排除）

- **跨会话导航**：大纲只作用于当前会话，切换会话/查看历史会话列表不属于本规格。
- **按助手消息或工具调用建刻度**：刻度只有一层，只对应用户消息；不提供「展开看这一轮调了哪些工具」的树形结构。
- **窄屏替代入口**：窄于阈值时不提供任何替代入口（不隐藏成按钮、不做抽屉），与 Codex 的行为保持一致。
- **键盘跳转快捷键**（上一条/下一条用户消息）：独立需求，不在本规格内。
- **搜索/过滤大纲项**：按关键字过滤刻度不在本规格内，找某句话见 [transcript-find.md](./transcript-find.md)。
