# 功能规格说明：操作确认对话框

**特性分支**：`action-confirm-dialog`
**创建日期**：2026-07-29
**设计稿**：[Figma — 操作确认对话框](https://www.figma.com/design/EiDsFbqhDRmPgFlrZkEkwE/mcp-test?node-id=2294-1496)

## 用户场景与测试 *（必填）*

### 用户故事：消息回滚二次确认（优先级：P1）

作为用户，我在点击消息的回滚按钮后，希望先在应用内看到居中的确认对话框并明确告知后果，再决定是否执行，以避免误操作丢失对话与文件更改；且在 VS Code、JetBrains 与桌面应用中看到完全一致的确认界面。

**为什么是这个优先级**：回滚会删除消息并撤销文件更改，属于破坏性操作；目前三端各自弹宿主原生确认（VS Code 模态框 / JetBrains 对话框 / 操作系统弹窗），样式与交互不统一。

**独立测试**：hover 一条用户消息并点击回滚按钮，验证屏幕中央出现确认对话框；点击「确定」执行回滚，点击「取消」或按 Esc 不执行任何操作。

**验收场景**：

1. **假设**对话中有多条消息，**当**用户点击某条用户消息的回滚按钮时，**则**屏幕中央显示确认对话框（标题「确定要回滚到此消息吗？」，描述「这将删除之后的所有消息并撤销相关的文件更改。」），此时不执行回滚。
2. **假设**确认对话框已显示，**当**用户点击「确定」（或按 Enter）时，**则**执行回滚并关闭对话框。
3. **假设**确认对话框已显示，**当**用户点击「取消」或按 Esc 时，**则**对话框关闭，对话与文件保持不变。
4. **假设**用户在 VS Code、JetBrains 或桌面应用中触发回滚，**当**确认流程出现时，**则**三端均显示同一个应用内确认对话框，不再出现宿主原生弹窗。

### 用户故事：删除会话二次确认（优先级：P1）

作为桌面应用用户，我在侧边栏点击删除会话时，希望看到与回滚一致的应用内确认对话框，而不是浏览器原生 confirm 弹窗，以获得统一的视觉与交互体验。

**为什么是这个优先级**：删除会话（尤其 worktree 会话）不可逆；浏览器原生 confirm 样式简陋且与应用主题不一致。

**独立测试**：在桌面应用侧边栏点击某会话的删除图标，验证应用内确认对话框出现；确认后删除会话，取消后不删除。

**验收场景**：

1. **假设**侧边栏存在会话条目，**当**用户点击删除图标时，**则**屏幕中央显示确认对话框，标题为「确定删除会话「X」？」（X 为会话标题）。
2. **假设**被删会话是 worktree 会话，**当**确认对话框显示时，**则**描述文案明确告知将一并删除 worktree 目录与临时分支、未提交改动将丢失。
3. **假设**确认对话框已显示，**当**用户点击「确定」时，**则**执行删除；点击「取消」或按 Esc 时不删除。

### 边界情况

- **流式生成中点击回滚按钮怎么办？** 保持现状：直接忽略，不弹确认对话框。
- **确认对话框显示期间重复触发怎么办？** 同一时刻最多存在一个操作确认对话框，新的触发被忽略。
- **点击遮罩会关闭对话框吗？** 不会。破坏性操作要求显式选择「取消」或「确定」（Esc 可取消）。
- **浅色主题下可读吗？** 全部颜色取自 `--vscode-*` 主题变量，亮暗主题均可读。

## 需求 *（必填）*

### 功能需求

- 共享 webview 必须提供通用操作确认对话框组件：全屏遮罩 + 居中卡片，卡片内含警告图标、标题、可选描述、「取消」「确定」按钮；标题、描述、按钮文案均由调用方传入。
- 对话框样式必须遵循设计稿：卡片宽 360px、内边距 16px、圆角 6px，面板背景 + 部件边框 + 投影；窄面板（如 IDE 侧边栏）下卡片宽度自适应收窄，左右各保留至少 32px 边距；标题 12px 中粗（前景色），描述 12px 常规（描述前景色）；按钮高 28px、最小宽 64px、圆角 6px、13px 半粗，主按钮使用按钮主题色，次按钮透明背景 + 输入框边框色；全部颜色使用 `--vscode-*` 变量以适配亮暗主题。
- 警告图标必须为 16px 警示三角形，颜色为设计稿警示黄 `#FFCC00`。
- Esc 必须等同于「取消」，Enter 必须等同于「确定」；点击遮罩不得关闭对话框。
- 同一时刻最多存在一个操作确认对话框。
- 消息回滚的确认必须在 webview 内完成：点击回滚按钮后先弹确认对话框，用户确认后才向宿主发送回滚命令；VS Code 扩展、JetBrains 插件、桌面应用宿主收到回滚命令后必须直接执行回滚，不再弹各自的原生确认。
- 桌面应用侧边栏删除会话必须复用同一组件，替代浏览器原生 `window.confirm`；普通会话仅显示标题，worktree 会话必须附加警示描述（一并删除 worktree 目录与临时分支、未提交改动将丢失）。

### 关键实体 *（如果功能涉及数据则包含）*

- **操作确认对话框**：共享 webview 中的通用模态组件，属性包括标题、可选描述、确认/取消按钮文案与两个回调。
