# 功能规格说明：桌面端设置与账户

> 拆分自 `desktop-app.md`（Wave Desktop 总纲），本文档仅承载该主题的用户故事与验收场景；跨主题的边界情况与非目标按主题分发至各文件。

## 用户场景与测试

### 用户故事：设置页面（优先级：P1）

作为用户，我希望通过侧边栏账户区「更多」菜单中的「设置」打开完整的设置页面，在左侧导航分组中浏览当前生效的全部配置与状态（语言、主题（桌面端）、上下文长度、AGENTS.md、自动记忆、项目插件、技能、子代理、钩子、MCP 服务），并可直接修改「全局设置」与「个性化」中的基础配置项，以便了解并调整当前环境的配置全貌。

**为什么是这个优先级**：设置页是桌面端的管理中心，用户拍板按原型做成全页面（覆盖会话区）。2026-08-31 曾拍板全部导航项只读展示（配置修改走 CLI 命令与配置文件）；2026-09-01 原型走查用户恢复部分可编辑：全局设置（AI 回复语言/上下文长度）与个性化（自动记忆开关/轮次）提供编辑控件与保存按钮（对齐旧配置弹窗交互），保存经 `updateConfiguration` RPC 写回配置并即时生效，其余视图（AGENTS.md 文本区、技能/子代理/钩子/MCP）保持只读浏览或原有管理形态；VSCE/JetBrains 无侧边栏账户区，同样以编辑器区域标签页 webview 承载（对齐 plan 标签页的呈现机制，从现有配置入口/命令打开）。2026-09-02 走查追加「主题」选择（仅桌面端展示，三态与行为见「主题设置」故事）：主题为桌面端本地显示偏好（不写入共享配置），选择即生效并持久化。

**独立测试**：desktop 点击「更多」→「设置」验证全页面导航（7 项 3 组，全部可进入）；全局设置/个性化修改语言、上下文长度、自动记忆开关与轮次并保存，验证新值生效（配置回发刷新展示）；VSCE/JetBrains 从命令面板/设置入口打开编辑器区域标签页 webview，验证内容与 desktop 一致；钩子视图按事件分组展示已配置命令（用户级/项目级双 tab）；MCP 视图展示服务器列表（类型/端点/连接状态/工具数）并可连接/断开；项目设置视图展示 SDD 开关状态并可切换。

**验收场景**：

1. **假设**desktop 侧边栏账户区已展示，**当**用户点击「更多」菜单中的「设置」，**则**会话区切换为设置页面全页面（侧边栏保持可见），页面显示左侧导航与右侧内容区；再次点击当前会话的「返回」或关闭方式可回到会话视图。
2. **假设**设置页面已打开，**当**用户查看左侧导航，**则**必须按原型分为三组共 7 项：「通用」（全局设置/个性化）、「工作区」（项目设置）、「AI 与扩展」（技能/子代理/钩子/MCP 服务），当前激活项有高亮态；浏览类视图不出现编辑控件，「全局设置」「个性化」仅对可编辑项展示控件。
3. **假设**用户点击「全局设置」，**当**进入该视图，**则**必须显示「基础设置」卡片，展示当前生效的 AI 回复语言（中文 zh-CN / English en-US）与上下文长度（K 值）：语言为下拉选择（中文/English）、上下文长度为数字输入（16–1000 K），提供「保存」按钮；保存成功回发新配置刷新展示，保存失败显示错误提示。桌面端卡片在 AI 回复语言下方还显示「主题」选择（跟随系统/浅色/深色，默认跟随系统），该行选择即时生效并持久化、不依赖「保存」按钮，VSCE/JetBrains 不显示主题行（选项行为见「主题设置」故事）。
4. **假设**用户点击「个性化」，**当**进入该视图，**则**必须显示两块内容：「AGENTS.md」（用户级/项目级两个 tab，文本区只读展示对应文件内容，不可编辑）与「自动记忆规则」（开启自动记忆为开关、触发记忆提取会话轮次为数字输入（1–100 轮），提供「保存」按钮；保存成功回发新配置刷新展示，保存失败显示错误提示）。项目级 AGENTS.md 仅展示当前项目内容，无项目切换按钮。
5. **假设**「个性化」AGENTS.md 文本区只读展示，**当**用户切换用户级/项目级 tab，**则**文本区内容随之切换为对应文件的最新磁盘内容，切换不产生任何写入。
6. **假设**用户点击「钩子」，**当**进入该视图，**则**必须只读展示钩子配置，提供「用户级/项目级」双 tab 切换（对齐个性化视图）：按事件分组（如 PreToolUse、PostToolUse、UserPromptSubmit、SessionStart 等）展示每个事件下已配置的命令及可选参数（异步、超时、匹配器），未配置任何钩子的事件组不显示或显示空态说明；全部内容只读，无编辑控件。
7. **假设**用户点击「MCP 服务」，**当**进入该视图，**则**必须展示 MCP 服务器列表（名称、类型（stdio/sse/http）、命令或端点 URL、连接状态（已连接/连接中/断开/错误）、可用工具数），提供「用户级/项目级」双 tab 切换：用户级 tab 读取 `~/.wave/mcp.json`、项目级 tab 读取项目根 `.mcp.json`；每个服务器提供「连接/断开」操作（对齐现有 MCP 连接管理能力），不提供新增/删除/编辑服务器配置的控件。
8. **假设**用户点击「项目设置」，**当**进入该视图，**则**必须展示内置插件 SDD 开关状态（读取项目 `.wave/settings.json` 合并后的 `enabledPlugins`）；开关为唯一交互控件——切换开关写回配置文件并立即生效（插件技能与引导无需重启会话），其余内容只读。
9. **假设**用户点击「技能」或「子代理」，**当**进入该视图，**则**按来源 Tab 展示列表（项目来源 Tab 平铺，无项目分组卡片），提供详情查看、新建、编辑、删除等管理操作，与 agents-command / skills-command 规格一致。
10. **假设**VSCE/JetBrains 宿主环境，**当**用户通过命令面板（如「打开设置」）或现有设置入口打开设置，**则**必须在编辑器区域打开设置标签页 webview（对齐 plan 标签页：VSCE 为编辑器区域面板、JetBrains 为编辑器标签页），内容与 desktop 设置页一致（同一导航结构与视图）；再次调用打开时复用已打开的标签页而非新建。
11. **假设**设置页任一视图打开，**当**用户修改了全局设置/个性化的可编辑项但未点击保存，**则**切换导航项或离开设置页不产生任何消息、不写入任何配置；仅点击「保存」时经 `updateConfiguration` 写入配置。

### 用户故事：上下文用量指示器（优先级：P2）

作为用户，我希望在输入工具栏看到当前上下文已用百分比（圆环进度 + 数字），以便了解上下文占用情况并在接近上限时通过 `/compact` 主动压缩。

**为什么是这个优先级**：压缩是 CLI 已有能力（`/compact` 命令与自动压缩），webview 需新增用量推送与展示，是批次 2 的原型功能之一；用量展示为纯展示元素（非按钮、无点击行为），压缩入口不依赖该元素。

**独立测试**：三端（desktop/VSCE/JetBrains）打开会话并发送消息后验证工具栏出现上下文用量指示器与百分比；指示器非按钮（不在 Tab 序、点击无行为）；输入 `/compact` 触发压缩并在完成时更新百分比；欢迎页（新会话未发送消息）验证指示器不显示。

**验收场景**：

1. **假设**会话已开始（非欢迎页）且输入工具栏可见，**当**用户查看工具栏，**则**权限模式按钮左侧必须显示「上下文用量」指示器，视觉形态为圆环进度图标 + 百分比数字（对齐原型，如仅显示「24%」，环的填充比例与百分比一致）；说明「已使用 24%」在指示器的 `title`/`aria-label` 中；指示器为纯展示元素（`span`，非按钮），不在 Tab 序中、点击无任何行为。
2. **假设**用户需要手动压缩上下文，**当**用户在输入框输入 `/compact` 并确认时，**则**触发与 CLI 等效的上下文压缩（压缩入口为斜杠命令与自动压缩，不依赖工具栏指示器）；压缩完成后指示器百分比随最新用量更新。
3. **假设**会话处于欢迎页（新对话未发送消息），**当**用户查看输入区，**则**不得显示上下文用量指示器（对齐原型：仅非欢迎态显示）。
4. **假设**宿主尚未推送用量信息，**当**指示器渲染，**则**显示空圆环（不显示百分比数字）；收到用量推送后显示圆环填充与百分比。
5. **假设**会话上下文用量随对话增长，**当**用量推送到达，**则**指示器百分比实时更新（含压缩后回落）。
6. **假设**用户切换到已有上下文用量的历史会话，**当**会话恢复完成，**则**指示器显示该会话上次的用量百分比（对齐 CLI：用量随会话恢复加载，无需等待新一轮对话或新消息）。

### 用户故事：账户卡片（优先级：P1）

作为用户，我希望在侧边栏底部看到账户卡片：登录状态下展示头像、姓名，点击弹出用量浮层（套餐用量/API 额度），并在「更多」菜单中打开设置、企业控制台、帮助文档或退出登录，以便了解账户状态。

**为什么是这个优先级**：账户卡片是桌面端侧边栏的核心运营入口，后端接口已就绪（issue #1986），按契约实施。

**独立测试**：desktop 未登录状态验证整条登录按钮与登录流程；登录后验证头像（邮箱前缀首字母占位）与姓名（邮箱前缀）、用量浮层（套餐用量进度条百分比、API 额度金额）、toast 信息类 1s 自动消失、帮助文档在浏览器新标签打开、远程主机标注。

**验收场景**：

1. **假设**用户未登录，**当**查看侧边栏底部，**则**必须显示整条「登录」按钮，点击后走现有 SSO 登录流程；登录成功后按钮区域切换为账户信息。
2. **假设**用户已登录，**当**查看账户卡片，**则**必须显示首字母圆形占位头像与姓名（登录邮箱前缀；无邮箱时显示「已登录」），姓名/头像热区右侧为「更多」按钮。
3. **假设**用户点击账户信息热区，**当**用量浮层弹出，**则**显示「套餐用量」（进度条+百分比，0% 为红并提示充值引导；后端未下发套餐时整块不渲染）与「API 额度」（已用/剩余金额，两位小数千位分隔；后端 limit 为空=共用团队余额，显示「已消耗 ¥x」（x 为本人累计消耗金额）；limit 为 0 视为已用完）。
4. **假设**用户点击「更多」菜单，**当**菜单展开，**则**必须包含「设置 / 企业控制台 / 帮助文档 / 退出登录」四项（退出登录为危险色分隔项）：「设置」打开设置页面，「企业控制台」打开对应网址，「帮助文档」在浏览器新标签页打开 `serverUrl + /docs`，「退出登录」执行登出并回到未登录状态。
5. **假设**信息类 toast 弹出（无操作按钮），**当**展示，**则**必须约 1 秒后自动消失；带操作按钮的 toast（如更新、查看会话）保持既有不自动消失行为。
6. **假设**账户卡片在远程主机会话的聚焦分屏下，**当**查看，**则**登录态/用量/菜单登录项必须跟随聚焦分屏所属主机（远程主机标注主机名，本地不标）。
7. **假设**网络/服务器状态变化或手动刷新，**当**账户用量轮询触发，**则**用量保持最新（轮询失败时保留上次成功显示）。

## 非目标（明确排除）

- **设置页其余 2 个导航项的完整功能**：钩子/MCP 服务本批仅占位（「即将推出」），不提供可编辑控件。
- **设置页在 IDE 宿主的高保真容器差异**：VSCE/JetBrains 的设置标签页 webview 内容与 desktop 设置页一致，但容器（编辑器区域标签页）为宿主自身形态，不做 desktop 全页面式布局。
- **上下文压缩的自动触发**：压缩仅由用户点击按钮或 `/compact` 命令触发，不引入自动压缩策略；用量百分比仅展示，不做压缩建议弹窗。
