# 功能规格说明：Diff 命令

**创建日期**：2026-11-13

## 用户场景与测试 _（必填）_

### 用户故事：查看未提交改动（优先级：P1）

作为用户，我希望输入 `/diff` 就能看到工作区里还没提交的改动，以便在决定是否提交或继续让 agent 改之前先自己过一遍。

**为什么是这个优先级**：这是日常最常看的那一份差异，也是「agent 到底动了什么」的第一落点；没有它，用户只能离开终端去敲 `git diff`。

**独立测试**：可以在一个 git 仓库里改一个文件、加一个未跟踪文件，然后输入 `/diff`，验证两个文件都出现在列表里、各自带 `+N -M` 统计，选中后能看到逐行 diff。

**验收场景**：

1. **假设** 工作区有 1 个已修改文件和 1 个未跟踪的新文件，**当** 用户输入 `/diff` 时，**则** 覆盖层显示 "Uncommitted changes" 标题、文件列表与合计统计（`2 files changed +3 -1`），输入框隐藏。
2. **假设** 文件列表可见，**当** 用户选中一个文件并按 `Enter` 时，**则** 进入该文件的详情视图，逐行展示 diff：新增行绿色、删除行红色、hunk 头青色。
3. **假设** 处于详情视图，**当** 用户按 `Esc` 时，**则** 回到文件列表且视图位置不变；再按一次 `Esc` 才关闭覆盖层、恢复输入框。
4. **假设** 差异内容超过覆盖层高度，**当** 用户按 `PgDn` / `PgUp`（或 `Ctrl+d` / `Ctrl+u`、`↑` / `↓`）时，**则** 详情视图滚动，顶部出现 `↑ N more`、底部显示 `↓ N more`。

---

### 用户故事：回看某一轮对话改了哪些文件（优先级：P2）

作为用户，我希望把差异范围收窄到「刚才那一轮」，以便在长会话里确认某个具体需求对应的改动，而不是在一大坨未提交改动里翻找。

**为什么是这个优先级**：未提交改动是累计的；对话轮次是用户脑子里真正的分界线，但只有把「这一轮动了哪些文件」摆出来才好核对。

**独立测试**：可以让 agent 连续两轮各自修改不同的文件，输入 `/diff` 后用 `←` / `→` 在 "Uncommitted changes" 与 "Turn N" 之间切换，验证每轮只列出该轮改过的文件及其 diff。

**验收场景**：

1. **假设** 会话里已有两轮分别修改过文件，**当** 用户按 `→` 时，**则** 覆盖层切到 "Turn 2"，副标题显示该轮用户请求的摘要（超长截断），并列出该轮改过的文件。
2. **假设** 正在看某一轮的差异，**当** 用户按 `←` 时，**则** 回到上一档（最左是 "Uncommitted changes"），选中项重置为第一个文件。
3. **假设** 某一轮只有读取类工具、没有改任何文件，**当** 用户切换轮次时，**则** 该轮不出现为可选来源（不展示空条目）。
4. **假设** 同一轮里同一个文件被改了两次，**当** 用户查看该文件时，**则** 两次改动按顺序合并展示，`+N -M` 为累计值。

### 用户故事：桌面端用 `/diff` 打开差异面板（优先级：P2）

作为桌面端用户，我手还在输入框里、刚看完 agent 这一轮的改动就想核对文件，希望敲 `/diff` 就能把右侧的「差异」面板打开，而不是先去点面板菜单或记快捷键。

**为什么是这个优先级**：桌面端的差异面板本来只有「空态网格 / ＋ 菜单 / 菜单栏 / 快捷键」几个入口，全都要先离开输入区；斜杠命令是唯一「手不用挪」的入口。反过来，VS Code / JetBrains 用编辑器自己的 diff 视图、手机远控页没有面板，所以这条命令只属于桌面端。

**独立测试**：在桌面端会话里输入 `/diff` 并发送，验证右侧出现「差异」tab、且没有消息被发给模型；面板已经开着时再敲一次，验证仍是同一个 tab。

**验收场景**：

1. **假设** 桌面端会话中右侧面板未打开，**当** 用户输入 `/diff` 并发送，**则** 右侧打开「差异」面板（内容与从菜单打开完全一致，见 `desktop/desktop-diff-panel.md`），这段文本不进对话、也不发给模型。
2. **假设** 「差异」tab 已经存在，**当** 用户再次输入 `/diff`，**则** 激活已有的那个 tab，不出现第二个差异 tab（与 `/tasks` 同样的单实例语义）。
3. **假设** 用户用的是 VS Code / JetBrains / 手机远控页，**当** 打开斜杠弹窗、或手打 `/diff`，**则** 弹窗里不出现这条命令（这些入口没有差异面板），手打的文本按普通消息处理、不报错。

### 边界情况

- **工作区基准**：差异的比对基准是**会话工作根**（会话打开时的目录，只有进入/退出 worktree 时才会变），agent 在会话里 `cd` 过不影响它。
- **不在 git 仓库**：覆盖层显示 "Not a git repository"，而不是空列表或报错。
- **仓库处于变基 / 合并 / 拣选等中间态**：覆盖层明确提示「有 X 正在进行，没有可信的差异」，而不是把半成品状态当成用户的改动。
- **二进制文件**：列表里标 `binary`，详情说明无文本差异，不渲染乱码。
- **超大差异**：单文件 diff 被截断时标注 `(truncated)`；覆盖层高度按终端高度收敛（约 60%），其余靠滚动查看。
