# 云端编程：远程主机上的后台会话

把会话放到 SSH 远程主机上跑，就是这里的「云端编程」：代码、依赖、构建环境都在远端，本地只负责看和指挥。会话由远端 daemon 托管——**关掉桌面端，它仍在远端继续运行**。

## 连接远程主机 {#cloud-connect}

在新对话里，点工作目录选择器左侧的主机下拉 →「添加主机」，填 `ssh user@hostname -p port` 形式的连接串，连上后点「浏览…」选远端目录即可开始会话。整个 CLI 子进程经 `ssh <host> -- wave --stdio` 在远端执行，读写文件、搜索、bash、git 等工具全部作用在远端文件系统，右侧的终端与差异面板同样跑在远端机器上（体验与 VS Code Remote-SSH 一致）。远端只需要系统 Node.js >= 22：桌面端会经 ssh 推送本机内置的同一份 CLI（按字节比对，不一致才推），远端不必 npm 装包，也不必出网。

## 关掉桌面端，任务继续跑 {#cloud-background}

- **断线不停**：ssh 中断、锁屏睡眠、直接退出桌面端，远端会话照常生成与执行；远端 daemon 空闲也不退出，任务跑完后再连上还是同一个进程。
- **回来即接上**：重新打开应用连上该主机，侧边栏直接列出后台会话并标注「运行中」/「待确认」，点进去是**接入**而不是重放历史——断线期间产生的消息、正在流式输出的回复都补回来，发送、中断、审批照常；应用还开着时断线（网络闪断、锁屏唤醒）会自动重建隧道接回，不必手动点侧边栏。
- **审批会等你**：没有客户端连接时遇到需要确认的步骤，会话挂起为「待确认」不继续推进；接回后弹出确认框，确认即继续。
- **删除即终止**：删掉一条后台会话，远端对应的 agent 一并终止。

## 边界 {#cloud-limits}

- 通信全走 ssh 隧道，远端 daemon 不监听公网，也不新增凭据体系（沿用现有 ssh 密钥）。
- 远端机器重启、或 CLI 升级重启 daemon 时，断线前正在进行的任务会终止；历史会话仍能从远端转录恢复，不会留下假的「运行中」状态。
- 后台保活只对远程会话生效：本地会话在退出应用时照常终止。
